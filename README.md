# NEOX Cloud Live ☁️

Public browser-based NEOX Cloud server simulation.

## v0.1

- 🟢 Shared-looking NEOX-01 server dashboard
- 📊 Live CPU/RAM metrics
- ⏱️ Uptime counter
- 🖥️ Simulated cloud console
- 📜 Live event logs
- ▶️ `start`, `stop`, and `restart`
- 🔎 `status`, `processes`, `network`, and `help`
- 💾 No database required for the first prototype

### Important

This version is intentionally a **simulation**. Commands run only inside the browser and do not execute arbitrary commands on a real machine.

## Roadmap

1. Shared real-time state between visitors
2. Multi-user event synchronization
3. Multiple virtual servers
4. Accounts and permissions
5. Server file manager
6. Optional real-server mode with explicit authorization
